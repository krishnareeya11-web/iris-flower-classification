# iris-flower-classification
Classifies iris flower species using KNN and Decision Tree in Python  
# Iris Flower Classification

A machine learning project that predicts the species of an iris flower
from its sepal and petal measurements.

## Tools
Python, pandas, matplotlib, scikit-learn

## Method
- Loaded the Iris dataset and explored it with histograms
- Split the data into 80% training and 20% testing
- Trained K-Nearest Neighbors and Decision Tree classifiers
- Compared them using accuracy score

## Result
KNN accuracy: 1.0%
Decision Tree accuracy: 1.0%

## How to run
Open the notebook in Google Colab and run all cells.
